# 개발과 공개본 보완 기록

## 당시 프로젝트

KT AIVLE School 미니프로젝트 2차의 AI 면접관 과제입니다. 김건우는 면접 진행 검토 고도화와 주제 전환 흐름을 담당했습니다. 팀원과 각각 만든 구현안 중 김건우 안이 채택됐으며, 주제 전환 시 대화 단절감을 프롬프트 반복 수정으로 개선했다고 회고했습니다. 정확한 수정 문구·횟수는 남아 있지 않아 새 문구를 당시 작성물로 소급하지 않습니다.

기존 GitHub 소스에는 이력서 분석·질문 전략·2항목 평가·큐/주제 관리·심화 질문 코드가 있습니다. README는 이 공개 코드가 제공하는 기능을 기준으로 구성했습니다. 팀 확장 실습의 5항목 가중 평가·reflection·RAG·Gradio 전체를 개인 단독 구현으로 표시하지 않습니다.

## 2026-10-29 공개 실행본 보완

- ChatPromptTemplate·StateGraph·END import와 종료 노드 연결
- LLM 클라이언트를 실제 호출 시점에 생성: API 키 없는 import/도움말/테스트 지원
- 그래프 1회 실행이 답변 1개만 평가하고 다음 질문을 반환하도록 실행 경계 정리
- 5답변 종료, 심화 횟수 제한, 잘못된 action 응답과 빈 답변 처리
- 질문 전략의 스키마 정규화·검증과 첫 주제 초기화
- 큐·대화·평가 목록을 복사해 실패 시 입력 상태 보존
- 주제 전환 연결 프롬프트에 이전 답변과 목표 질문을 전달
- CLI 경로 인수, 선택적 키 파일, 한 번의 보고서 출력, 종료/오류 처리
- 실제 LangGraph와 FakeListChatModel로 오프라인 회귀 테스트 추가

이 보완은 현재 저장소 정비 작업입니다. 당시 해결 경험이나 새로 측정한 면접 품질 성과로 기재하지 않습니다. 테스트는 결정된 모델 출력을 이용한 흐름 검증이며 실제 GPT 응답 품질이나 운영 배포 검증을 대신하지 않습니다.
